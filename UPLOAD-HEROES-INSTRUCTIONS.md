## 🚀 Now You Need to Upload

### **EASIEST METHOD: Cloudinary Dashboard**

1. **Go to Cloudinary Media Library:**
   https://console.cloudinary.com/console/media_library

2. **Click "Upload" button**

3. **For each category (1-18), upload the heroImage.jpg:**
   
   - **Category 1:**
     - File: `src/assets/images/category1/heroImage.jpg`
     - Public ID: `heroImage1`
   
   - **Category 2:**
     - File: `src/assets/images/category2/heroImage.jpg`
     - Public ID: `heroImage2`
   
   - **... continue for all 18 categories**

4. **How to set Public ID during upload:**
   - When uploading, click "Advanced"
   - Find "Public ID" field
   - Enter: `heroImage1` (or 2, 3, etc.)
   - Click "Upload"
